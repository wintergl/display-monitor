# Privacy

The published source has no analytics SDK, account login, remote upload client, or third-party package dependencies. Screen captures, recordings, and settings are handled locally. Copying to the clipboard or exporting a file happens through user actions; other software with access to the clipboard or export directory can read that content.

Screen Recording allows access to on-screen content. Accessibility and input-control permissions allow the relevant menu bar and pointer operations. Enable only the features and permissions you need. Protected content may be unavailable.

Settings and artifact state use macOS preferences and Application Support locations. Screenshot exports default to a Display Monitor Screenshots folder on the Desktop and can be changed in Settings. Local diagnostic state can include app identities, display layout, and file paths. Do not post raw logs, settings backups, or screen recordings without reviewing them.

The public repository excludes private desktop captures, user data backups, device serial numbers, and local account credentials. Developer ID signer identity is public metadata in the signed downloadable app; it is not a private signing key.
