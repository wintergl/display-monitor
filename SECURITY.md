# Security

Please report vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/wintergl/display-monitor/security/advisories/new). Avoid public issues for credentials, personal content, or exploitable details while a report is being assessed.

The latest public release is the supported reporting target. Include the version/build, OS version, reproduction steps with synthetic content, and expected/actual behavior. Do not include live credentials, account databases, device identifiers, or personal recordings.

Screen Recording and Accessibility are sensitive OS permissions. The native menu bar visibility implementation uses a private framework and may change across system updates. Review [compatibility](docs/COMPATIBILITY.md) before distributing a derivative.
